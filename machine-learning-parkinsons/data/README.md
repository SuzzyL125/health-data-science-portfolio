# Data availability

The original feature dataset is not included in this repository because its redistribution license was not documented in the course folder.

To reproduce the analysis, place the course-provided training data at:

```text
machine-learning-parkinsons/data/parkinsons_voice_features.csv
```

Expected fields:

- `id`: participant identifier
- `class`: binary outcome, healthy control or Parkinson's disease
- acoustic predictor columns: 753 features in the original dataset

Before sharing any replacement dataset, confirm its license and verify that it contains no protected health information.
